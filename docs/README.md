## 历史归档

所有原 P2／P3／P4 记录保留原文件名，迁入 `archive/p2/`、`archive/p3/`、`archive/p4/`；整理前的进度和规划全文也保留快照。完整目录和按问题查找入口见[归档索引](archive/README.md)。

归档正文的“当前”“下一步”和命令是当时记录，可能指向旧固件。最新操作以本页链接的当前文档为准。主机测试、目标构建、烧录和硬件结果分别记录；归档不会把待验事项改为通过。
