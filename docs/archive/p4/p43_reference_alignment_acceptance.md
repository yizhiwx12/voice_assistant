## 本批实现

| 模块 | 职责与边界 |
| --- | --- |
| `main/audio/playback_reference.*`、`max98357a_audio.*` | 播放编号在已清空DMA的新代次绑定一次；不在每次写入时给下一完成块强行换号。SD稳定低电平物化已知零参考；切换块、异常格式和丢事件保留未知／缺口标记。 |
| `main/audio/reference_resampler.*` | 连续有状态2/3多相FIR，191个48kHz原型抽头，7kHz低通；240个24kHz输入对应160个16kHz输出。固定群延迟为95/48000秒，约1.979ms；跨块保存历史与相位，缺口／重建后暖机样本带无效标记。 |
| `main/audio/ics43434_microphone.*` | ISR只观测DMA完成边界和溢出，提供一致的64位样本计数／时间快照；实际读取样本保持独立统计，不用任务读取时刻冒充采样时刻。AFE模型初始化后受控重建采集／播放边界，避免启动积压被当作有效对齐。 |
| `main/audio/reference_timeline.*` | 将完成参考映射到RX主采样时线，PSRAM历史固定30块、每块160样本，约300ms。有限旧代次可按编号查询；未知区间不补成有效静音。 |
| `main/audio/reference_monitor.*`、`audio_service.*` | 任务侧消费、重采样和对齐；RX向后查询80ms的20ms窗口，统计完整／部分数字参考覆盖。观测不送入AFE，也不改变现有录放和云端轮次。 |
| `main/audio/acoustic_delay_probe.*` | 播报时观测带RX样本编号的原始麦克风帧和对应参考，估计有限范围内的相关峰；只作诊断，不自动调整相位或宣告声学校准完成。 |

时钟拟合采用至少1秒观测窗，允许范围为标称采样率±2000ppm，采样率估计每窗最多平滑25ppm；对齐通过有界分数步长连续变化处理慢漂移，不周期性整块丢／补。DMA锚点过旧、采样时线无效、RX溢出、时间跳变和超出范围均明确报告失配。观测失败时现有半双工链路保留。

这仍是数字时间线。DMA完成、参考完整覆盖或较高相关都不能独立证明扬声器的精确声学出声时间；滤波群延迟已单列，扬声器、声程、房间混响及麦克风路径仍须固定摆位实测。

## 相关延迟诊断

播报期间，采集任务把原始麦克风320样本帧和RX样本编号送入固定12帧PSRAM诊断队列。等待80ms后，任务侧每200ms最多分析一次，查询对应1600样本参考及有效掩码，在0～80ms范围按1ms网格计算归一化相关。

低能量、参考不全、相关过低、多峰歧义和搜索边界峰会被拒绝。相关输入只在有限RAM缓冲中保留，不落盘、不上传，不自动修改重采样或对齐参数。本批没有双讲检测，用户须在助手播报时保持安静，远端单讲场景才适合解释相关结果；噪声或双讲时`rejected`增加本身不等于功能断线。

`acoustic_delay_probe`输出尝试、通过、拒绝、延迟样本、相关值、峰值间隔、极性`polarity`和字符串`reject_reason`；`calibrated=0`是本批预期状态。通过结果只是当前测试窗口的候选附加延迟观测，不能作为精确声学停播、完整AEC验收或自动插话已就绪的证明。

## 用户补验与复测步骤

以下是本版历史复测步骤；当前B收尾已提供按播放保留通过候选的新固件，按[新批验收](p43b_acoustic_statistics_acceptance.md)补重复远端单讲、主观取消及任务资源，不需重做本页14分钟数字观测。需要复测本版时保持风扇关闭、固定摆位及原服务端，在ESP-IDF终端执行：

```powershell
cd C:\esp-project\voice_assistant
idf.py -p COM7 -b 115200 flash monitor
```

端口与设备实际不同时替换COM7；无需擦除Flash。完整`flash`按项目清单部署应用、分区及配套模型。

1. 连接就绪、尚未录音时输入`?`，保存`memory`、`audio_task_stacks`、`local_frontend`、`playback_reference`、`reference_resampler`、`reference_alignment`及`acoustic_delay_probe`行。任务栈的`capture_free_min`／`playback_free_min`单位为字节。
2. 输入`a`，用中文进行两轮交互，包含一轮较长回复。助手播报期间保持静默，获得远端单讲参考与相关观测；每轮播完后输入`?`。
3. 再生成较长回复，正在播音时输入`c`。确认声音停止、旧声音不会恢复；输入`?`后重新输入`a`并完成新一轮。保留取消前后代次与播放编号。
4. 输入`m`，再按`r`说完整中文句子、按`s`结束。确认原始手动路径的识别、文字和播报仍正常。
5. 总观察至少5～10分钟后再次输入`?`。提交初始、正常播放、取消后及末尾日志，并简述是否听清播报、有无新增卡顿和取消后旧声恢复。出现断连时另保留同epoch／turn的服务端首因。
