## 改动后的屏幕

助手播报时，底部继续显示两行状态：

```text
播报中，不自动打断
本地检测：静音
```

检测到人声候选时，第二行变成：

```text
本地检测：人声
```

前端启动中、异常或关闭时仍显示对应真实状态，不固定显示“静音”。`本地检测`表示前端输出的讲话判断；它不表示当前音频正在上传或已经转写成文字。普通单麦 `M` 固件也适用此标签，不把未启用 AEC 的状态误标成 AEC 结果。

在独立 AEC 测试固件中，该状态来自 AEC 后的 VAD。播放期间本地处理持续运行，但控制器仍暂停自动创建新云端轮次，因此用户此时讲话不会立即打断助手，也不会自动上传。按 `s` 不会把播报期间的讲话补交识别；本批仍是观察功能。

改动复用已有状态变化 revision 和屏幕刷新，不调整采集／播放／前端任务调度、队列、参考年龄保护、云模型或接线。非自动监听时的 `VAD 观测` 文案统一改为 `本地检测`，产品界面使用同一种说法。

## 怎么观察

先使用本批独立 AEC 固件，保持设备和麦克风／扬声器位置不变，关闭风扇，采用平时的播报音量。在每种场景下看屏幕底部第二行，并记录短暂变化还是长时间停在人声。

1. **只有助手播报，你保持安静。** 如果大部分时间显示“静音”，说明此场景下本地检测没有持续把扬声器回声判成人声。若长时间显示“人声”，记录当时音量和大致时刻，这是残余回声或检测误判的线索，不单凭屏幕定因。
2. **助手仍在播报时，你说一句完整短句。** 观察第二行是否转成“人声”，说完后是否回到“静音”。助手继续播报是预期行为；此时只观察检测变化。
3. **播完或按 `c` 后开始下一轮。** 这部分用户已反馈正常，本批只在显示变更后按需回归，不把它重新登记为当前故障。

屏幕 VAD 变化只能说明前端输出中检测到讲话候选，不能单独证明双讲时每个字都保留、声音完全无损或量化 ERLE 达标。要评价具体词句保真仍需受控音频对照或后续自动插话功能的识别结果。本批不要求持续保存用户录音，也不自动开启音频落盘。
